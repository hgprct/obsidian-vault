
## 0. Common setup

### 0.1 Spaces and data

| Symbol                                                                          | Meaning                                                                                             |
| ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| $\mathcal X$                                                                    | state space                                                                                         |
| $\mathcal X = \mathbb R^d$                                                      | continuous case                                                                                     |
| $\mathcal X = \mathcal V^L$                                                     | discrete case: sequences of length $L$ over a vocabulary $\mathcal V$, $\lvert\mathcal V\rvert = V$ |
| $\mathtt m$                                                                     | mask token (absorbing case); $\bar{\mathcal V} = \mathcal V \cup \{\mathtt m\}$                     |
| $x^i$                                                                           | $i$-th coordinate (pixel or token), $i \in [L] = \{1,\dots,L\}$                                     |
| $p_{\text{data}}$                                                               | data distribution on $\mathcal X$                                                                   |
| $\mathcal D = \{x^{(j)}\}_{j=1}^{n} \overset{\text{iid}}{\sim} p_{\text{data}}$ | training set                                                                                        |
| $\Delta(\mathcal S)$                                                            | probability simplex over a finite set $\mathcal S$                                                  |
| $\mathrm H$, $\mathrm I$, $\mathrm{KL}$                                         | entropy (differential in the continuous case), mutual information, KL divergence                    |
### 0.2 Forward (noising) process

Time $t \in [0,1]$. At $t=0$ we have data and at $t=1$ the reference (noise) law. The marginals are $p_t$, with $p_0 = p_{\text{data}}$.

**Continuous (Gaussian paths).**

$$x_t = \alpha_t x_0 + \sigma_t \varepsilon, \qquad \varepsilon \sim \mathcal N(0, I_d),$$

with $\alpha_0 = 1,\ \sigma_0 = 0$ and $\alpha_1 \approx 0,\ \sigma_1 \approx 1$. Rectified flow is the special case $\alpha_t = 1-t,\ \sigma_t = t$, which gives the target velocity $\dot x_t = \varepsilon - x_0$.

**Discrete (factorized CTMC).** Each coordinate is corrupted independently:

$$q_t(x_t^i \mid x_0^i) = \alpha_t\, \delta_{x_0^i}(x_t^i) + (1-\alpha_t)\, \mu(x_t^i),$$

- masked / absorbing: $\mu = \delta_{\mathtt m}$
- uniform: $\mu = \mathrm{Unif}(\mathcal V)$

The process is generated by rate matrices $Q_t$, and $\alpha_t$ decreases from $1$ to $0$.

### 0.3 Parameters and epistemic law

|Symbol|Meaning|
|---|---|
|$\theta \in \Theta \subseteq \mathbb R^P$|network parameters|
|$f_\theta(x_t, t)$|raw network output (any parameterization)|
|$q(\theta) \approx p(\theta \mid \mathcal D)$|**epistemic law** over parameters|
|$q_{\text{ens}} = \frac1K \sum_{k=1}^K \delta_{\theta_k}$|ensemble approximation (e.g. trained on data subsets)|
|$q_{\text{LA}} = \mathcal N(\theta^\star, \Sigma_\theta)$|Laplace approximation around the MAP $\theta^\star$|
|$\mathbb E_\theta,\ \mathrm{Cov}_\theta$|shorthand for $\mathbb E_{\theta \sim q},\ \mathrm{Cov}_{\theta \sim q}$|

> [!important] Convention **Epistemic** always means "induced by the randomness of $\theta \sim q$, with everything else held fixed". What "everything else" contains is exactly what differs between the four categories.

### 0.4 Sampler and step size

- **Time grid:** $\tau = (1 = t_0 > t_1 > \dots > t_N = 0)$.
- **Step sizes:** $h_n = t_{n-1} - t_n$. We write $h = 1/N$ for a uniform grid.
- **Sampler noise:** $\xi = (\xi_0, \xi_1, \dots, \xi_N) \sim \rho$. Here $\xi_0$ is the initial draw and $\xi_n$ is the noise injected at step $n$.
- **One-step map:** $\Psi^{n}_\theta : \mathcal X \times \Xi \to \mathcal X$, which sends $(x_{n-1}, \xi_n) \mapsto x_n$.

**Discrete step size.** In masked diffusion, time is not intrinsic: the model is time-agnostic. The step-size parameter is instead the **number of tokens per step** $k$, with $N = L/k$. We write $h$ generically and read it as $k$ in that case.

## 1. Prediction: $\hat x_0$

### Continuous

$$\hat x_{0,\theta}(x_t, t) \;\approx\; \mathbb E[x_0 \mid x_t] \;=\; \frac{x_t + \sigma_t^2\, \nabla_x \log p_t(x_t)}{\alpha_t} \quad \text{(Tweedie)}.$$

Every standard Gaussian parameterization ($\varepsilon$, score, $v$, velocity, $x_0$) maps to $\hat x_0$ through an affine map:

$$\hat x_{0,\theta}(x_t,t) = A_t\, x_t + B_t\, f_\theta(x_t,t).$$

The coefficients $(A_t, B_t)$ depend only on the parameterization and the schedule.

### Discrete

For each position $i$, the network outputs a categorical distribution

$$\pi^i_\theta(\cdot \mid x_t, t) \in \Delta(\mathcal V), \qquad \pi^i_\theta(v \mid x_t, t) \approx p(x_0^i = v \mid x_t).$$

In the masked case, $\pi^i_\theta$ is only used at positions where $x_t^i = \mathtt m$.

### Epistemic quantity

For a fixed query $(x_t, t)$:

$$  
\mathcal U_1(x_t,t) := \mathrm{Cov}_\theta\!\big[\hat x_{0,\theta}(x_t,t)\big]  
\qquad \text{(continuous)}  
$$ $$  
\mathcal U_1^i(x_t,t) := \mathrm I\big(x_0^i;\theta \mid x_t\big)  
= \mathrm H\!\big(\mathbb E_\theta \pi^i_\theta\big) - \mathbb E_\theta \mathrm H\big(\pi^i_\theta\big)  
\qquad \text{(discrete, BALD)}  
$$

> [!warning] Posterior ≠ epistemic The spread $\mathrm H(\pi^i_\theta)$ of a _single_ model is the spread of the true posterior $p(x_0^i \mid x_t)$, so it is **aleatoric**. Only the disagreement across $\theta$ is epistemic.

**Step-size dependence:** none. $\mathcal U_1$ is a function of $(x_t, t)$ only. Any $h$-dependence must enter through the distribution of the query $x_t$ that the sampler visits (exposure bias).

## 2. Field: score, velocity, rate matrix

### Continuous

- **Score field:** $s_\theta : \mathbb R^d \times [0,1] \to \mathbb R^d$, with $s_\theta(x,t) \approx \nabla_x \log p_t(x)$.
- **Probability-flow velocity:** $$v_\theta(x,t) = \frac{\dot\alpha_t}{\alpha_t}\, x \;-\; \Big(\sigma_t \dot\sigma_t - \frac{\dot\alpha_t}{\alpha_t}\sigma_t^2\Big)\, s_\theta(x,t).$$ The exact-score ODE $\dot x = v(x,t)$ transports $p_1$ to $p_0$. In flow matching, $v_\theta$ is learned directly.

### Discrete

- **Learned reverse generator (rate matrix):** $R_\theta(x, y; t)$ for $x \neq y$. It satisfies $R_\theta(x,y;t) \ge 0$ and $R_\theta(x,x;t) = -\sum_{y \ne x} R_\theta(x,y;t)$.
- **Masked case.** Only single-coordinate jumps that unmask a position are allowed: $$R_\theta\big(x,\ x^{i \leftarrow v};\ t\big) = \lambda_t\, \pi^i_\theta(v \mid x, t)\, \mathbb 1[x^i = \mathtt m], \qquad \lambda_t = \frac{-\dot\alpha_t}{1-\alpha_t}.$$ Here $x^{i\leftarrow v}$ denotes $x$ with coordinate $i$ set to $v$.

### Epistemic quantity

The epistemic object is a random **field** $\theta \mapsto v_\theta$ (or $\theta \mapsto R_\theta$). Its covariance kernel is

$$\mathcal C_t(x, x') := \mathrm{Cov}_\theta\big[v_\theta(x,t),\, v_\theta(x',t)\big] \in \mathbb R^{d \times d}.$$

Under Laplace with linearization:

$$\mathcal C_t(x,x') \approx J_t(x)\, \Sigma_\theta\, J_t(x')^\top, \qquad J_t(x) = \partial_\theta v_\theta(x,t)\big|_{\theta^\star}.$$

The **off-diagonal** part ($x \ne x'$, and across times $t \ne t'$) is what makes errors correlated across sampler steps. These are the cross-terms that FLARE drops.

**Step-size dependence:** none. The field is defined independently of any sampler.

## 3. Sample: $X^h_\theta(\xi)$

### Definition

The **sampler map** sends $(\theta, \xi)$ to a sample:

$$X^h_\theta(\xi) := \Psi^N_\theta \circ \cdots \circ \Psi^1_\theta\big(x_{\text{init}}(\xi_0)\big), \qquad \xi \sim \rho.$$

### Continuous: ODE with an Euler step

$$\Psi^n_\theta(x) = x - h_n\, v_\theta(x, t_{n-1}),$$

- The sampler is deterministic given $\xi_0$, with $x_{\text{init}} = \xi_0 \sim \mathcal N(0, I_d)$.
- **Exact limit:** the flow map $\Phi_\theta^{1\to0}$, giving $X^0_\theta(\xi) = \Phi^{1\to0}_\theta(\xi_0)$.
- An SDE sampler adds $\sqrt{h_n}\, g_{t_{n-1}}\, \xi_n$ at each step.

### Discrete: masked, $k$ tokens per step

- **Start:** $x_{\text{init}} = (\mathtt m, \dots, \mathtt m)$.
- **Order:** at step $n$, an ordering rule selects a set of positions $z_n \subset \{i : x^i_{n-1} = \mathtt m\}$ with $\lvert z_n\rvert = k$.
- **Sampling:** each position $i \in z_n$ is sampled **independently** by Gumbel-max: $$x_n^i = \arg\max_{v \in \mathcal V} \big[\log \pi^i_\theta(v \mid x_{n-1}) + G^i_{n,v}\big], \qquad G^i_{n,v} \overset{\text{iid}}{\sim} \mathrm{Gumbel}(0,1),$$ with $\xi_n = (G^i_{n,v})_{i,v}$.
- **Reference limit:** $k = 1$ gives the exact joint of the model, decoded in any order.
- **If the order rule depends on $\theta$** (confidence, entropy, or MI), then $z_n = z_n(\theta, x_{n-1})$ and $\theta \mapsto X^h_\theta(\xi)$ becomes piecewise constant.

### Epistemic quantity

Hold the noise $\xi$ fixed (common random numbers):

$$\mathcal U_3(h) := \mathbb E_\xi\, \mathrm{Cov}_\theta\big[X^h_\theta(\xi) \mid \xi\big] \qquad \text{(continuous)},$$ $$\mathcal U_3^{\text{disc}}(h) := \mathbb E_\xi\, \mathbb E_{\theta,\theta' \overset{\text{iid}}{\sim} q}\Big[\tfrac1L\, d_{\text{Ham}}\big(X^h_\theta(\xi),\, X^h_{\theta'}(\xi)\big)\Big] \qquad \text{(discrete)}.$$

Law of total covariance over $(\theta, \xi)$:

$$\mathrm{Cov}_{\theta,\xi}[X^h] = \underbrace{\mathbb E_\xi \mathrm{Cov}_\theta[X^h \mid \xi]}_{\text{epistemic at fixed seed}} + \underbrace{\mathrm{Cov}_\xi\, \mathbb E_\theta[X^h \mid \xi]}_{\text{seed-driven}}.$$

> [!caution] Coupling-dependent $\mathcal U_3$ depends on how $\xi$ is shared across $\theta$. For example, Gumbel-max and inverse-CDF coupling give different values. It is therefore a property of the pair (sampler, coupling), **not** of the model.
> 
> Linearized continuous ODE case, the continuum limit of FLARE:
> 
> $$\mathrm{Cov}_\theta[X^0_\theta(\xi)] \approx S(\xi)\,\Sigma_\theta\,S(\xi)^\top, \qquad S(\xi) = \partial_\theta \Phi^{1\to0}_\theta(\xi_0)\big|_{\theta^\star},$$
> 
> where $S$ solves the forward sensitivity ODE (or is obtained via the adjoint).

**Step-size dependence:** yes, through $\Psi^n_\theta$ and $N$.

## 4. Distribution: $p^h_\theta$

### Definition

The **sampler-induced law** is the pushforward of the noise law through the sampler:

$$p^h_\theta := \big(X^h_\theta\big)_\# \rho.$$

|Symbol|Meaning|
|---|---|
|$p^h_\theta$|the law that model $\theta$ actually samples from with step size $h$|
|$p^0_\theta$|exact-sampler limit: the flow-map law, or the $k=1$ joint|
|$\bar p^h := \mathbb E_\theta\, p^h_\theta$|Bayesian model average (posterior predictive)|

### Epistemic quantity (coupling-free)

$$  
\mathcal U_4(h) := \mathrm I^h(\theta; X)  
= \mathrm H\big(\bar p^h\big) - \mathbb E_\theta\, \mathrm H\big(p^h_\theta\big)  
= \mathbb E_\theta\, \mathrm{KL}\big(p^h_\theta \,\|\, \bar p^h\big).  
$$

- In the continuous case, the entropies are differential, but $\mathrm I$ remains well-defined and invariant under reparameterization.
- **Discrete chain rule** over the decoding blocks $z_1, \dots, z_N$: $$\mathrm I^h(\theta; X) = \sum_{n=1}^N \mathrm I\big(\theta;\, X^{z_n} \mid X^{z_{<n}}\big).$$ With $k > 1$, each term is computed under the factorized product $\prod_{i \in z_n} \pi^i_\theta$. Comparing these terms to the joint ($k=1$) terms isolates the step-size effect.

### Error decomposition (total vs. data)

$$  
\underbrace{\mathrm d\big(p^h_\theta,\, p_{\text{data}}\big)}_{\text{total}} \;\le\;  
\underbrace{\mathrm d\big(p^h_\theta,\, p^0_\theta\big)}_{\text{discretization / factorization } \mathcal E_{\text{disc}}(h)} \;+\;  
\underbrace{\mathrm d\big(p^0_\theta,\, p_{\text{data}}\big)}_{\text{learning error}}.  
$$

This holds for any metric $\mathrm d$. For KL there is no triangle inequality, so the chain-rule form is used instead. In the discrete case,

$$\mathcal E_{\text{fact}}(k) := \mathrm{KL}\big(p^{(1)}_\theta \,\|\, p^{(k)}_\theta\big).$$

**Step-size dependence:** yes, and coupling-free.

## 5. Summary

||Object|Map from $\theta$|Epistemic measure|Depends on $h$|Coupling-free|Toy ground truth|
|---|---|---|---|---|---|---|
|**1**|$\hat x_0$ / $\pi^i$|$\theta \mapsto \hat x_{0,\theta}(x_t,t)$|$\mathrm{Cov}_\theta$, BALD|✗ (only through visited $x_t$)|✓|✓ exact $\mathbb E[x_0 \mid x_t]$|
|**2**|$v_\theta$ / $R_\theta$|$\theta \mapsto$ field|kernel $\mathcal C_t(x,x')$|✗|✓|✓ exact score / rates|
|**3**|$X^h_\theta(\xi)$|$\theta \mapsto$ sample at fixed $\xi$|$\mathbb E_\xi \mathrm{Cov}_\theta$, Hamming|✓|✗|✓|
|**4**|$p^h_\theta$|$\theta \mapsto$ law|$\mathrm I^h(\theta; X)$|✓|✓|✓ (exact on a small HMM)|

**Dependency chain:**

$$\underbrace{\theta \mapsto f_\theta}_{\text{network}} \;\xrightarrow{\text{affine}}\; \underbrace{\hat x_{0,\theta}}_{1} \;\xrightarrow{\text{Tweedie}}\; \underbrace{v_\theta,\ R_\theta}_{2} \;\xrightarrow{\Psi^n,\ h}\; \underbrace{X^h_\theta(\xi)}_{3} \;\xrightarrow{(\cdot)_\#\rho}\; \underbrace{p^h_\theta}_{4}.$$

> [!tip] Working hypothesis for the choice
> 
> - Categories 1–2 are **local ingredients**: inputs to the propagation, not the object of study.
> - Category 3 is the natural object for a **continuous ODE** analysis (sensitivity, FLARE-style recursion), but it depends on the coupling.
> - Category 4 is the only one that is **h-dependent, coupling-free, and defined in both settings**. It is the candidate primary target.

## Open notation choices

- [ ]  Time direction: keep $t=0$ as data throughout, including when citing flow-matching papers that use the opposite convention.
- [ ]  Choose $\mathrm d$ for the continuous decomposition: $W_2$ or a KL/chain-rule form.
- [ ]  Decide whether a $\theta$-dependent unmasking order is in scope. It makes the map $\theta \mapsto X$ discontinuous.
- [ ]  SDE samplers: add a separate aleatoric term $\mathbb E_\theta\, \mathrm{Cov}_\xi[X^h_\theta]$.
